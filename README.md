# Сладкие сны — сервис бронирования номеров гостиницы

Демонстрационный экзамен, специальность 09.02.09 «Веб-разработка»
(КИМ 09.02.09-2-2027, ГИА ДЭ БУ, разработка веб-приложений на стороне сервера).

Стек: **Python 3 + Flask + SQLite**, вёрстка — предоставленный шаблон (Bootstrap 5, шрифт Golos).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows   (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python run.py
```

Сайт откроется на http://127.0.0.1:5000. База данных `instance/hotel.db` создаётся и заполняется
автоматически при первом запуске (схема — `app/schema.sql`).

Тесты: `python -m unittest discover -s tests -t . -v`

## Доступ администратора

Страница входа: `/login` · Логин: `hotel123` · Пароль: `adminHotel`

### Функционал

* **Каталог** (`/`) — 6 случайных номеров, фильтр по категориям (несколько сразу), «Применить» / «Сбросить фильтр».
* **Бронирование** (`/order/<id>`) — поля: имя, фамилия (кириллица, пробелы, точки, тире), телефон `+7(XXX)XXX-XX-XX`,
  e-mail, даты `ДД.ММ.ГГГГ`. Ошибки показываются под полями. После успеха — «Заявка успешно отправлена!»,
  заявка получает статус «Новая».
* **Календарь** — периоды с одобренными бронями недоступны для выбора; сервер перепроверяет пересечения.
* **Панель администратора** (`/admin`, только после входа) — список заявок, «Одобрить», «Отклонить», «Удалить».
  Нельзя одобрить заявку, пересекающуюся по датам с уже одобренной.

### Безопасность

Параметризованные SQL-запросы, автоэкранирование в шаблонах (защита от XSS), CSRF-токены на всех POST,
пароль администратора хранится как хеш, HttpOnly/SameSite cookie, заголовки CSP / X-Frame-Options /
X-Content-Type-Options, закрытые админ-маршруты, любая валидация выполняется на сервере.
